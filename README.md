# Spam-detection-model
A machine learning project that detects whether a text message is Spam or Not Spam using the Naive Bayes classification algorithm. The project includes text preprocessing, feature extraction, model training, and prediction using Python and machine learning libraries.
# Features
- Text preprocessing and cleaning
- Feature extraction from text
- Naive Bayes classification
- Spam and non-spam message prediction
- Model evaluation using classification metrics
- Interactive web interface built with Streamlit
# Technologies Used
- Python
- pandas
- Scikit-learn
- Naive bayes
- Streamlit
# How It Works
1) Load the spam message dataset.
2) Clean and preprocess the text data.
3) Convert text into numerical features using a text vectorization technique.
4) Train a Naive Bayes classifier.
5) Test the trained model using unseen messages.
6) Predict whether a message is Spam or Not Spam.
